# نُور — موقع وتطبيق ويب قابل للتثبيت (V0.23.0)

هذه النسخة تجمع واجهة الموقع مع تطبيق ويب تقدّمي (PWA) من نفس قاعدة الكود؛ يمكن فتحها كموقع، وفي المتصفحات المدعومة تثبيتها على الشاشة الرئيسية وتشغيلها في نافذة مستقلة. **هذه ليست حزمة Android APK أصلية.**

## الموجود
- صفحة `/feed` لعرض المنشورات العامة وإنشاء منشور وإضافة تعليق والتفاعل مع المنشور عبر API.
- صفحة `/account` لتسجيل الحساب والدخول والخروج.
- واجهة عربية RTL متجاوبة للموبايل والكمبيوتر.
- Web App Manifest وأيقونات واختصار للحساب.
- زر تثبيت يظهر إذا أعلن المتصفح دعم التثبيت.
- Service Worker يخزّن الغلاف العام والصفحة الرئيسية للاستخدام المحدود دون اتصال.
- استثناء `/api` و`/account` وملفات Next الداخلية من التخزين.
- أساس API للحسابات والمنشورات والتعليقات والتفاعلات والملفات الشخصية والمتابعة والحظر وفرض الخصوصية ورفع الصور (presigned)؛ التكامل والاختبار الفعليان غير مؤكدين.

## التشغيل المحلي

راجع أيضًا ملف `RUN.md` للخطوات المختصرة.
المتطلبات: Node.js 22+ وpnpm 10+ وDocker Compose. انسخ `.env.example` إلى `.env` واضبط الأسرار و`NEXT_PUBLIC_API_URL` و`WEB_ORIGIN` حسب عناوينك، ثم `docker compose up -d postgres redis minio` و`pnpm install`، وبعدها جهّز Prisma حسب مخطط المشروع وشغّل `pnpm dev`. الموقع على `http://localhost:3000` وAPI على `http://localhost:4000/api/health`.

## التثبيت على الهاتف
بعد نشر الموقع عبر HTTPS، افتحه بمتصفح يدعم تثبيت PWA. إذا لم يظهر زر التثبيت، استخدم قائمة المتصفح ثم «إضافة إلى الشاشة الرئيسية» إن كان الخيار متاحًا.

## حدود التحقق
التثبيت الفعلي، وضع عدم الاتصال، تثبيت الاعتماديات، البناء الإنتاجي وربط قاعدة البيانات لم تُختبر في بيئة تشغيل فعلية هنا. لا تنشر النسخة للجمهور قبل إكمال الاختبارات وإعداد HTTPS والأسرار وقيود الطلبات.

## مسارات الواجهة
- `/` الصفحة التعريفية.
- `/account` التسجيل وتسجيل الدخول وإدارة الخروج.
- `/feed` موجز المنشورات العامة، نشر منشور، تعليق، وإعجاب/إلغاء إعجاب.
- `/u/[username]` الملف الشخصي العام مع عدّادات المتابعة وزر متابعة/حظر/رسالة والمنشورات حسب الخصوصية.
- `/messages` الرسائل الخاصة (محادثات مباشرة).
- `/notifications` الإشعارات داخل التطبيق.
- `/search` البحث عن مستخدمين ومنشورات.
- `/stories` القصص (24 ساعة).

ملاحظة: واجهة الموجز تستخدم API؛ إذا كانت قاعدة البيانات غير مُهيّأة أو لم يُشغّل API فستظهر رسالة خطأ بدل بيانات تجريبية.


### الاختبارات والمعرّفات

- `pnpm check:ids`: فحص ساكن لمعرّفات الصفحات والعناصر التفاعلية والمنشورات والتعليقات.
- `pnpm check:source`: فحوصات بنية المشروع الأساسية.
- `pnpm test:e2e`: اختبارات Playwright للمتصفح تشمل إنشاء الحساب وتسجيل الدخول، نشر منشور، التعليق، التفاعل، وفحص تفرّد معرّفات DOM.

لتشغيل اختبارات المتصفح محليًا: شغّل PostgreSQL، ثم نفّذ `pnpm install` و`pnpm --filter @nour/api prisma:generate` و`pnpm --filter @nour/api prisma:push`، ثم `pnpm -r build` و`pnpm exec playwright install chromium` وبعدها `pnpm test:e2e`. يلزم ضبط `DATABASE_URL` و`NEXT_PUBLIC_API_URL` و`WEB_ORIGIN`. إضافة الاختبارات إلى CI لا تعني أنها اجتازت التشغيل بالفعل؛ راجع نتيجة الـ workflow الفعلية.

فحص المعرّفات الساكن لا يغني عن فحص DOM بعد تشغيل التطبيق؛ هذا الفحص موجود الآن ضمن اختبارات Playwright لكنه يظل غير مؤكد حتى تُشغّل الاختبارات بنجاح.
